# BestWallet para Android

Aplicación de finanzas personales creada por Estuar Víquez.

Descarga la APK firmada desde [Releases](https://github.com/Estuar05/BestWallet-releases/releases/latest). Android 8.0 o posterior.

Las versiones 3.3 y posteriores pueden buscar nuevas publicaciones desde **Ajustes → Actualizaciones**, descargar el APK y abrir el instalador de Android. Para actualizar conserva la instalación existente: no desinstales ni borres datos. Android solicita el permiso de instalación y la confirmación final.

Este repositorio contiene únicamente APK y notas de versiones. El código fuente se mantiene privado. Las cuentas y finanzas se guardan cifradas localmente en cada teléfono; este repositorio no contiene ni recibe datos financieros, cuentas, contraseñas o copias personales.

El actualizador verifica HTTPS, tamaño, SHA-256, identificador de paquete, versión superior y la misma firma que la aplicación instalada. Los archivos de actualización se llaman `BestWallet-N.apk`, donde N es el código de versión de Android.

La aplicación es de uso personal y no se conecta a bancos ni a Gmail. Las recomendaciones de ahorro se basan en los ingresos, gastos y compromisos que registres.
